핵심 설계 포인트

  • 단일 워커 + 큐 — GPU 자원을 직렬화(동시성 1). 여러 잡이 와도 하나씩 처리.
  • 프로세스 그룹 격리 — start_new_session=True 로 실행, 취소 시 자식까지 killpg 로 정리, 재기동 시 orphan 재입양.
  • 마이크로서비스 분리 — 무거운 GPU/OCR/LLM 은 별도 포트 서비스로 위임, gateway 는 오케스트레이션만.
  • 원본 보존 검수 — Ketcher 로 사람이 교정하되 RDKit canonical 비교로 실제 수정분만 corrected 로 기록, 추출 원본 보존.
